🎯 KEY FEATURES
================================================================================

✨ Coordinator Agent
   - Routes requests to appropriate agent
   - Uses LLM for intelligent routing
   - Aggregates responses

📚 Vocabulary Agent
   - Teaches words and definitions
   - Provides usage examples
   - Explains synonyms

📖 Grammar Agent
   - Explains grammar rules
   - Provides practice exercises
   - Corrects errors

💬 Conversation Agent
   - Practices dialogue
   - Natural conversation flow
   - Error correction

🔗 A2A Communication
   - Agent-to-agent messaging
   - Asynchronous operation
   - Message history tracking

📊 LangGraph Integration
   - Structured execution graphs
   - State management
   - Easy extensibility

🏠 Local LLM Support
   - Privacy-focused (no API keys)
   - Cost-effective (local computation)
   - Multiple model support
